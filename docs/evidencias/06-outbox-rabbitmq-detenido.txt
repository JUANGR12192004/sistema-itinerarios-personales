Fecha: 2026-11-18 23:00:31 -0500
Equipo: Darwin (arm64), Docker version 29.9.3, build 5457199

1) Se detiene RabbitMQ.
$ docker compose stop rabbitmq

2) Se crea un itinerario: la API responde 201 aunque RabbitMQ esté caído, porque solo escribe en
   PostgreSQL (itinerario + evento en la misma transacción).
$ curl -s -w '\nHTTP %{http_code}\n' -X POST http://localhost:8000/api/itineraries -H 'Content-Type: application/json' -H 'X-Correlation-ID: evidencia-outbox-20261118230006' -d '{"traveler_name": "Luis Gómez", "traveler_email": "luis@example.com", "departure_airport_id": 1, "arrival_airport_id": 5, "travel_date": "2027-01-02T08:00:00-05:00", "duration_minutes": 90}'
